# Repository Instructions

- Before changing code, read `HANDOFF.md` and the relevant sections of `README.md`.
- After every code change is implemented and verified, update the development documentation before committing or releasing.
- Always review and update `HANDOFF.md`. Also update `README.md` when user-facing behavior, installation, configuration, or operation changes.
- Keep documentation aligned with current behavior, verification results, version information, and known limitations. Remove stale status and completed TODOs.
- For releases, use this order: implement, verify, update documentation, bump the version, commit and push, tag, then verify the GitHub Release and all APK assets.
